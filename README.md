# Finito

This is a project I created to practice my front-end development skills, which I gained while working as an intern at Valencia Kommunikation AG.

Finito is a simple and elegant to-do list application that helps you manage your tasks efficiently.

## Live Demo

You can check out the live demo of the application [here](https://susietsow.github.io/finito/).

## Features

- Add new tasks to your to-do list
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Persistent storage using `localStorage`

## Technologies Used

- HTML
- CSS
- JavaScript

## Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

Make sure you have a modern web browser installed.

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/finito.git
   ```
2. Open the project directory:
   ```sh
   cd finito
   ```
3. Open `index.html` in your web browser to view the application.

## Usage

- To add a new task, type the task description in the input box and click the "add" button.
- To edit a task, click the "edit" button next to the task, make your changes, and click "save".
- To mark a task as completed, check the checkbox next to the task.
- To delete a task, click the "delete" button next to the task.
